# Aranya Mitra · అరణ్య మిత్ర

**A friend of the forest.** Aranya Mitra is a Google Gemini–powered web app that helps foragers and children — starting with the tribal communities of the Eastern Ghats — avoid poisonous wild plants and mushrooms. Take a photo of any wild plant, leaf, berry, or mushroom, and it explains in Telugu whether it's dangerous, why, the symptoms if eaten, and the first aid to give — with a one-tap call to 108.

By design, it **never says anything is safe to eat.** Because a photo can't confirm edibility and a wrong "safe" could cost a life, it only warns and always defaults to "don't eat" when unsure.

🌿 **Live app:** https://aranya-mitra.netlify.app

Built with Google Gemini (multimodal vision + multilingual) and a Netlify serverless backend that keeps the API key secure. Created for **Meet the Builders — Gen AI Academy (APAC Edition).**

> ⚠️ Guidance only — not a substitute for an expert or a lab. When in doubt, do not eat.
